
  # NurseLink

  This is a code bundle for NurseLink. The original project is available at https://www.figma.com/design/znuf9ORudP6yC9x7d3kyqh/NurseLink.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Known Limitations

  This is a capstone/demo project. It has not been through a HIPAA compliance review and referral notes (and all other data) are stored unencrypted in the database. Don't use it with real patient data.
